# 聊天式引导设计文档

## 概述

根据用户反馈，我们将重新设计引导流程，从表单填写式转变为完全聊天式的交互方式。这种方式更符合"Attention is all you need"的理念，让业务方专注于表达想法而非填写表单。

## 当前流程分析

当前的引导流程包括以下阶段：
1. **需求交流**：已经是聊天式界面，用户可以自由表达想法
2. **需求反思**：使用折叠面板展示反思结果，用户点击确认
3. **需求澄清**：使用问答表单收集具体信息
4. **需求确认**：使用表单确认收集的需求
5. **AI描述**：展示转换后的AI描述
6. **DevOps推荐**：展示推荐的DevOps方案
7. **知识建议**：展示相关知识建议
8. **方案生成**：生成最终方案

## 新流程设计

新的引导流程将保持统一的聊天界面，通过AI助手引导式提问收集信息：

1. **需求交流**：保持现有聊天界面，用户自由表达想法
2. **需求反思**：
   - AI助手在聊天中总结反思结果
   - 用户可以直接在聊天中确认或提出修改意见
3. **需求澄清**：
   - AI助手在聊天中提出澄清问题
   - 用户直接在聊天中回答
   - 每个问题回答后，AI助手提出下一个问题
4. **需求确认**：
   - AI助手在聊天中总结所有收集的需求
   - 用户可以直接确认或提出修改
5. **AI描述**：
   - AI助手在聊天中展示转换后的AI描述
   - 用户可以直接确认或请求修改
6. **DevOps推荐**：
   - AI助手在聊天中展示DevOps推荐方案
   - 可以使用富文本格式（代码块、列表等）增强可读性
7. **知识建议**：
   - AI助手在聊天中提供知识建议
   - 可以包含链接和引用
8. **方案生成**：
   - AI助手在聊天中展示最终方案
   - 提供下载或查看详细文档的选项

## 交互设计

### 聊天界面

- 统一的聊天界面贯穿整个流程
- 顶部保留进度指示器，显示当前所处阶段
- 右侧可选择性展示当前阶段的辅助信息（如需求列表、架构图等）
- 聊天消息支持富文本格式，包括：
  - 代码块
  - 表格
  - 列表
  - 链接
  - 图片/图表

### 引导式提问

- AI助手根据当前阶段提出相应问题
- 问题设计遵循自然对话流程，避免机械式提问
- 提供上下文相关的建议和示例，帮助用户回答
- 支持用户随时跳转到其他阶段或返回修改之前的回答

### 状态管理

- 在后端维护完整的对话历史和当前阶段状态
- 支持会话恢复，用户可以中断并稍后继续
- 每个阶段结束时保存关键信息，用于生成最终方案

## 技术实现

### 前端改造

1. **统一聊天组件**：
   - 扩展现有ChatInterface组件，支持富文本消息
   - 添加消息类型（问题、回答、确认、建议等）
   - 实现消息渲染器，根据消息类型显示不同样式

2. **阶段控制器**：
   - 实现阶段管理逻辑，控制AI助手提问流程
   - 根据当前阶段和用户回答决定下一步操作

3. **辅助信息面板**：
   - 实现可折叠的辅助信息面板
   - 根据当前阶段显示相关信息

### 后端改造

1. **对话管理**：
   - 扩展对话历史结构，支持阶段标记和消息类型
   - 实现阶段转换逻辑

2. **信息提取**：
   - 从聊天对话中提取关键信息
   - 实现自然语言理解，识别用户意图和回答内容

3. **响应生成**：
   - 根据当前阶段和对话历史生成下一个问题或响应
   - 实现上下文感知的回答生成

## 实现计划

1. 修改前端ChatInterface组件，支持富文本和不同消息类型
2. 实现阶段控制器，管理对话流程
3. 修改后端API，支持新的对话管理和信息提取
4. 实现各阶段的对话模板和逻辑
5. 整合现有功能到新的聊天流程中
6. 测试完整流程，确保功能正常

## 预期效果

- 更自然、流畅的用户体验
- 减少用户认知负担，无需适应不同界面
- 保持所有现有功能，同时提升交互体验
- 更好地体现"Attention is all you need"的理念
