## 项目背景

EinoDevOps助手是一个基于字节跳动开源的Eino框架开发的DevOps助手，旨在支持业务部门从想法到上线的全过程。项目的核心理念是"Attention is all you need"，通过AI技术赋能DevOps流程，提升研发效率。

## 核心功能

- **业务引导** - 引导业务人员从想法到明确需求
- **需求分析** - 分析需求，提供技术建议
- **架构推荐** - 推荐适合的架构方案
- **代码生成** - 生成高质量的代码
- **DevOps自动化** - 自动化DevOps流程
- **知识建议** - 提供相关知识建议

## 技术栈

- **后端** - Go语言，Eino框架
- **前端** - React，Tailwind CSS
- **DevOps工具** - Git，CI/CD，Kubernetes
- **CloudWeGo生态** - Kitex，Hertz，Netpoll等
