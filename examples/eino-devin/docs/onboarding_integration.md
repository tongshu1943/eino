# 引导流程与主助手集成文档

## 概述

引导流程与主助手的集成是EinoDevOps助手的核心功能，它将业务引导流程与DevOps自动化流程无缝连接，实现从想法到上线的全流程自动化。本文档描述了引导流程与主助手的集成方案，包括数据流、状态管理和交互设计。

## 集成架构

引导流程与主助手的集成采用基于Eino框架的图编排能力，主要包括以下组件：

1. **引导模块**：负责业务引导流程，包括需求交流、需求反思、需求澄清、需求确认、AI描述转换和DevOps推荐
2. **对话管理模块**：负责与用户的对话交互，理解用户意图，转发用户请求
3. **任务规划模块**：负责将用户需求分解为可执行的任务
4. **代码生成模块**：负责生成符合需求的代码
5. **DevOps模块**：负责自动化部署和运维
6. **工具集成模块**：负责与外部工具的集成

这些模块通过Eino的图编排能力连接，形成完整的工作流。

## 数据流

引导流程与主助手的数据流如下：

1. 用户通过对话管理模块输入项目想法
2. 对话管理模块将用户输入转发给引导模块
3. 引导模块进行需求交流、需求反思、需求澄清、需求确认、AI描述转换和DevOps推荐
4. 引导模块将处理结果（需求、AI描述、DevOps推荐）传递给任务规划模块
5. 任务规划模块将需求分解为可执行的任务，传递给代码生成模块
6. 代码生成模块生成符合需求的代码，传递给DevOps模块
7. DevOps模块进行自动化部署和运维，将结果反馈给用户

整个过程中，各模块通过Eino的图编排能力进行数据传递和状态管理。

## 状态管理

引导流程与主助手的状态管理采用基于会话的方式，主要包括以下状态：

1. **会话状态**：记录当前会话的基本信息，如会话ID、创建时间、更新时间等
2. **引导状态**：记录引导流程的状态，如当前步骤、完成情况等
3. **需求状态**：记录用户需求的状态，如需求点、功能范围、非功能需求等
4. **AI描述状态**：记录AI描述的状态，如AI任务描述、系统提示词、用户提示词等
5. **DevOps推荐状态**：记录DevOps推荐的状态，如架构推荐、流水线配置、工具推荐等
6. **任务状态**：记录任务的状态，如任务列表、完成情况等
7. **代码状态**：记录代码的状态，如代码仓库、分支、提交等
8. **部署状态**：记录部署的状态，如部署环境、部署结果等

这些状态通过Eino的状态管理能力进行管理，确保各模块之间的状态一致性。

## 交互设计

引导流程与主助手的交互设计采用基于Web的方式，主要包括以下页面：

1. **引导页面**：包括开始、需求交流、需求反思、需求澄清、需求确认、AI描述、DevOps推荐和方案生成等步骤
2. **主助手页面**：包括对话界面、任务列表、代码编辑器、终端和浏览器等组件
3. **知识建议页面**：包括知识建议列表、知识详情等组件

这些页面通过React和Ant Design组件库实现，提供优雅的用户体验。

## 前端实现

引导流程与主助手的前端实现采用React和Ant Design组件库，主要包括以下组件：

1. **App**：应用的根组件，负责路由管理
2. **OnboardingPage**：引导页面的主组件，包含引导流程的各个步骤
3. **ChatInterface**：对话界面组件，负责与用户的对话交互
4. **ReflectionComponent**：需求反思组件，负责展示需求反思结果
5. **ClarificationComponent**：需求澄清组件，负责需求澄清和需求点提取
6. **RequirementForm**：需求确认组件，负责需求确认和表单提交
7. **AIDescriptionComponent**：AI描述组件，负责展示AI描述结果
8. **DevOpsRecommendationComponent**：DevOps推荐组件，负责展示DevOps推荐结果
9. **KnowledgeSuggestionsComponent**：知识建议组件，负责展示知识建议

这些组件通过React的组件化和状态管理能力连接，形成完整的前端应用。

## 后端实现

引导流程与主助手的后端实现采用Go语言和Eino框架，主要包括以下模块：

1. **api**：API模块，负责处理HTTP请求
2. **onboarding**：引导模块，负责业务引导流程
3. **agent**：代理模块，负责与LLM的交互
4. **planner**：规划模块，负责任务规划
5. **codegen**：代码生成模块，负责代码生成
6. **devops**：DevOps模块，负责自动化部署和运维
7. **tools**：工具模块，负责与外部工具的集成
8. **knowledge**：知识模块，负责知识管理和建议

这些模块通过Eino的图编排能力连接，形成完整的后端应用。

## API设计

引导流程与主助手的API设计采用RESTful风格，主要包括以下接口：

1. **GET /api/onboarding/status**：获取引导状态
2. **POST /api/onboarding/start**：开始引导过程
3. **POST /api/onboarding/message**：发送消息
4. **POST /api/onboarding/analyze**：分析需求
5. **POST /api/onboarding/clarify**：澄清需求
6. **POST /api/onboarding/answer-question**：回答澄清问题
7. **POST /api/onboarding/add-requirement**：添加需求点
8. **POST /api/onboarding/convert-to-ai-description**：转换为AI描述
9. **POST /api/onboarding/get-devops-recommendations**：获取DevOps推荐方案
10. **POST /api/onboarding/submit**：提交需求表单
11. **POST /api/onboarding/generate-plan**：生成项目方案

这些接口通过Go的HTTP服务器实现，提供RESTful API服务。
